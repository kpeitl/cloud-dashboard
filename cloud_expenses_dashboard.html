How to Read This Dashboard

Invoice amounts are billed based on usage from two months prior. For example, an invoice issued in August reflects consumption from June.

The current month’s usage is displayed for monitoring purposes only and should be considered preliminary. These values are still being accumulated and may change until the end of the current month, when the total usage is fully calculated and finalized.
